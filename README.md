Rice Price Prediction System

This project predicts rice prices using Machine Learning models.

Models Used
- Gradient Boosting
- LSTM
- GRU

Features
- Data preprocessing
- Feature engineering
- PCA
- MAE, RMSE, MAPE evaluation

 How to Run
1. Install requirements
2. Run train_gbm.py
3. Run app.py
