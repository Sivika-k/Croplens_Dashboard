Rice Price Prediction System

This project uses Machine Learning techniques to predict rice prices 
using historical and real-time data.

Models Used
- Gradient Boosting
- LSTM
- GRU

Features
- Data preprocessing
- Feature engineering
- PCA
- Model evaluation using MAE, RMSE, MAPE

How to Run
1. Install required libraries
2. Run train_gbm.py
3. Run app.py
